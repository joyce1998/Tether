在 Mac 上安装

  1. 打开下载好的 DMG 文件。
  2. 在弹出的窗口里，把 Tether 拖到「应用程序」文件夹。
  3. 推出磁盘映像，然后在「应用程序」里打开 Tether。

用 ZIP 的话，先解压（Safari 会自动解压，其他浏览器下载的，双击它就行），得到 Tether.app，把它拖进「应用程序」，再打开。

要放进「应用程序」以后再打开。直接在磁盘映像或「下载」文件夹里打开的 Tether，以后没法自己更新。

第一次打开

Tether 没有经过 Apple 公证。没有公证的 App 从网上下载后，第一次打开会被 macOS 拦下来。放行一次之后，以后双击就能打开。

macOS 15 及更高版本（包括 macOS 26）：

  1. 双击 Tether。看到「未打开“Tether”」的提示，点「完成」。
  2. 打开「系统设置」，点边栏里的「隐私与安全性」，往下滚到「安全性」。
  3. 那里有一行「已阻止“Tether”以保护Mac。」，点旁边的「仍要打开」。
  4. 在弹出的「打开“Tether”？」对话框里确认打开（按钮写着「仍要打开」或「打开」），然后输入登录密码，或者用触控 ID。

「仍要打开」只在你尝试打开后大约一小时内出现。找不到的话，再双击一次 Tether，然后回到「隐私与安全性」。

macOS 12 到 14：在「访达」里打开「应用程序」文件夹，按住 Control 键点按 Tether，选「打开」，再点「打开」。也可以在设置里点「仍要打开」：macOS 13 和 14 在「系统设置」→「隐私与安全性」，macOS 12 在「系统偏好设置」→「安全性与隐私」→「通用」。

提示“Tether”已损坏，无法打开

在「终端」里运行下面这行，再打开 Tether：

xattr -dr com.apple.quarantine /Applications/Tether.app

这行命令只是去掉 macOS 给网上下载的文件加的隔离标记，不会改动 App 本身。

允许访问本地网络

放行之后，macOS 会问「允许“Tether”查找本地网络中的设备？」，点「允许」。手机是通过局域网连到 Mac 的，选了「不允许」，手机就连不上。点错了可以去「系统设置」→「隐私与安全性」→「本地网络」，把 Tether 打开。这个询问从 macOS 15 开始才有。

接下来就可以连接手机了。

在 Windows 上安装测试版

  1. 运行下载好的安装程序 Tether-0.5.1-win-x64-setup.exe（ARM64 版的文件名里是 arm64）。
  2. Windows 会显示蓝色的「Windows 已保护你的电脑」窗口，说 Microsoft Defender SmartScreen 阻止了无法识别的应用启动。这是因为 Tether 的安装程序没有代码签名，下载的人也还不多，Windows 认不出它。点「更多信息」，窗口里会多出「仍要运行」按钮，点它。
  3. 安装程序直接开始安装，不问装在哪里，也不需要管理员权限。装好后 Tether 会自己打开，开始菜单和桌面上也会有 Tether 的快捷方式。

下载时，浏览器也可能提示这个文件不常被下载，原因同上。在 Edge 里，把鼠标移到下载列表的这一项上，点「…」→「保留」，再点「显示更多」→「仍然保留」。

Tether 装在你自己的账户下（%LOCALAPPDATA%\Programs\tether），这台电脑上的其他账户要用的话，各自装一次。

允许 Tether 通过防火墙

第一次打开时，会弹出「Windows 安全中心警报」，说 Windows Defender 防火墙已阻止此应用的部分功能。勾上「专用网络」，点「允许访问」，之后如果弹出确认，点「是」。点了「取消」的话，手机就连不上。

还要确认电脑连的 Wi-Fi 是「专用网络」。Windows 常把新连上的网络设成「公用网络」，在公用网络上，防火墙会挡住手机的连接。在家里、公司这类你信任的网络上，打开「设置」→「网络和 Internet」→「WLAN」，点这个网络的属性，把「网络配置文件类型」改成「专用网络」。Windows 10 上是点网络名称，在「网络配置文件」里选「专用」。

点错了想改：打开「Windows 安全中心」→「防火墙和网络保护」→「允许应用通过防火墙」，点「更改设置」，找到 Tether，勾上「专用」，再点「确定」。

在通知区域找到 Tether

关掉 Tether 的窗口，它还在后台运行，图标在任务栏右下角的通知区域里。Windows 11 常把新图标收进「^」里面，可以把 Tether 的图标拖到任务栏上，让它一直显示。单击图标打开状态面板，双击打开主窗口，右键是菜单。

在 Linux 上安装测试版

Ubuntu、Debian 和基于它们的发行版（例如 Linux Mint）用 .deb，其他发行版用 AppImage。ARM 电脑选 arm64 版。

.deb

  1. 打开终端，进入下载文件夹（cd ~/Downloads，中文系统上可能是 cd ~/下载），运行下面这行。文件名前面的 ./ 不能省。 
    sudo apt install ./Tether-0.5.1-linux-amd64.deb
  2. 在应用菜单里打开 Tether，或者在终端里运行 tether。

Tether 装在 /opt/Tether。安装时最后可能出现一行以 N: Download is performed unsandboxed as root 开头的提示，这是 apt 在说它用 root 读了你文件夹里的安装包，不影响安装。在 Ubuntu 24.04 上，安装时还会加一份 AppArmor 配置，让 Tether 能照常使用沙盒。

AppImage

  1. 把下载好的文件放到一个自己的文件夹里，例如 ~/Applications。以后自动更新时，Tether 会直接替换这个文件。
  2. 给它加上运行权限：在文件管理器里右键它，选「属性」→「权限」，勾上「允许作为程序执行」；或者在终端里运行： 
    chmod +x ~/Applications/Tether-0.5.1-linux-x86_64.AppImage
  3. 双击打开。有的文件管理器双击不会运行它，就在终端里运行这个文件。

AppImage 不会自己出现在应用菜单里。Ubuntu 24.04 不让 AppImage 使用沙盒，这时 Tether 会在关掉沙盒的情况下运行，所以在 24.04 上更推荐用 .deb。打不开、提示和 FUSE 有关的错误时，在终端里运行这个文件，后面加上 --appimage-extract-and-run。

系统托盘

Tether 的图标在系统托盘里。单击图标打开主窗口；新建终端、配对设备、允许手机访问、防止休眠这些都在它的菜单里（有的桌面右键打开菜单，有的单击就是菜单）。

GNOME 默认没有系统托盘。Ubuntu 已经带了托盘扩展；Fedora、Debian 这类原版 GNOME，要先装上「AppIndicator and KStatusNotifierItem Support」扩展，图标才会出现。没有托盘也能用：关掉窗口后 Tether 还在后台运行，再打开一次 Tether，窗口就回来了（.deb 装的在应用菜单里打开，AppImage 就再运行一次那个文件）。

防火墙

Ubuntu 默认不开防火墙。你打开了 ufw 的话，放行 Tether 的端口（默认是 7420）：

sudo ufw allow 7420/tcp

用 firewalld 的发行版（例如 Fedora、openSUSE），手机连不上时运行：

sudo firewall-cmd --permanent --add-port=7420/tcp && sudo firewall-cmd --reload

核对文件

下载完可以核对文件是否完整、有没有被改动过：算出文件的 SHA-256，和下面列的对比，应该完全一样。命令里的文件名换成你下载的那个。

Mac：在「终端」里运行

shasum -a 256 ~/Downloads/Tether-0.5.1-mac-arm64.dmg

Windows：在 PowerShell 里运行。它输出的是大写字母，对比时不用管大小写

Get-FileHash "$HOME\Downloads\Tether-0.5.1-win-x64-setup.exe" -Algorithm SHA256

Linux：在终端里运行

sha256sum ~/Downloads/Tether-0.5.1-linux-amd64.deb

    这一版的校验值还没有发布，过一会儿再来看。

    0.5.1 的新变化

    • 有了 Windows 版和 Linux 版。在 Windows 上默认用 PowerShell。快捷键用 Ctrl+Shift 加一个键，单按 Ctrl 的组合（比如 Ctrl+C）照常发给终端。
    • Intel 处理器的 Mac 也能用了。
    • 自动检查更新：有新版本时提醒一次，点「更新」，Tether 换上新版本后自己重新打开，终端会恢复。
    • 分屏最多 9 个窗格。把侧栏里的终端拖到任意一个窗格的边上；⌘D、⇧⌘D 在聚焦的窗格旁边新开一个。
    • 「出门在外」向导：一步步装好 Tailscale、开启 HTTPS 地址、用手机重新配对、打开锁屏推送，每一步做完自动打勾。

    以前的版本

    更新到新版本

    从 0.5.1 开始，Tether 会自己检查更新。有新版本时它会提醒你一次，在「设置」里「有新版本」那一行点「更新」，Tether 下载新版本、核对过签名和 SHA-256，换上以后自己重新打开。终端会回到原来的目录，之前的输出也在；正在运行的程序会停止，所以有终端开着时 Tether 会先问你。更多说明在文档里。

    • Mac：Tether 要在「应用程序」文件夹里才能自己更新。
    • Windows：新版本在后台安装，装好后 Tether 自己打开。
    • Linux AppImage：Tether 直接替换原来那个文件，所以它要放在你自己能写入的文件夹里。
    • Linux .deb：Tether 没法自己替换系统目录里的文件。有新版本时它会提醒你，点「前往下载」回到这个页面，先退出 Tether，下载新的 .deb，再运行一次 sudo apt install ./文件名。

    还在用 0.5.0 的话，要按下面的步骤手动更新这一次，以后就不用了。

    从 0.5.0 手动更新

    1. 在菜单栏面板里点「退出 Tether」，确认框里点「退出」。退出前，Tether 会存好所有终端。
    2. 下载新版本的 DMG，打开它，把 Tether 拖到「应用程序」，提示已有同名项目时选「替换」。
    3. 打开新版本。它也是从网上下载的，第一次打开同样要在「隐私与安全性」里放行一次。

    配对过的手机和所有设置都存在 ~/.tether 里，换版本不受影响，手机不用重新配对。终端会按原来的名字回到原来的目录，之前的输出也在；正在运行的程序会停止。

    手机上的界面是电脑提供的网页。更新之后，在手机上把 Tether 关掉再打开一次，就是新版本的界面。

    卸载

    先关掉「登录时自动启动」（在菜单栏面板、通知区域的面板或者托盘菜单里），再退出 Tether。

    Mac

    1. 把「应用程序」里的 Tether 拖到废纸篓。
    2. 想把数据也删掉，在「终端」里运行下面这行。它会删除配对过的设备、设置和存下的终端。 
      rm -rf ~/.tether ~/Library/"Application Support"/Tether ~/Library/Caches/Tether ~/Library/Preferences/app.tether.mac.plist

    已经删了 App 才想起登录项的话，可以在「系统设置」→「通用」→「登录项与扩展」里把 Tether 移除（macOS 13 和 14 里叫「登录项」）；macOS 12 在「系统偏好设置」→「用户与群组」→「登录项」。

    Windows

    1. 打开「设置」→「应用」→「已安装的应用」，找到 Tether，点右边的「…」→「卸载」。Windows 10 上是「设置」→「应用」→「应用和功能」，点 Tether，再点「卸载」。
    2. 想把数据也删掉，在 PowerShell 里运行下面这行。 
      Remove-Item -Recurse -Force "$HOME\.tether", "$env:APPDATA\Tether", "$env:LOCALAPPDATA\tether-updater" -ErrorAction SilentlyContinue

    卸载以后，开机时还在启动 Tether 的话，在「设置」→「应用」→「启动」里把它关掉。

    Linux

    1. .deb：运行 sudo apt remove tether。AppImage：删掉那个文件。
    2. 想把数据也删掉，在终端里运行下面这行。 
      rm -rf ~/.tether ~/.config/Tether ~/.cache/tether-updater ~/.config/autostart/tether.desktop

    最后，在手机上把主屏幕上的 Tether 图标删掉。手机发来的照片和文件在下载文件夹的 Tether 文件夹里，是你自己的文件，上面的命令不会动它们。
