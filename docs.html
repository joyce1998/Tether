系统要求

  • Mac：macOS 12 Monterey 或更高版本。Apple 芯片和 Intel 处理器的 Mac 都能用，下载时选对应的版本。
  • Windows：Windows 10（1903 或更高版本）或 Windows 11，x64 或 ARM64 的电脑。Windows 版现在是测试版，见常见问题。
  • Linux：64 位（x64 或 arm64）的桌面 Linux，例如 Ubuntu 22.04、Debian 12、Fedora 39 或更新的版本。Linux 版现在是测试版，见常见问题。
  • 手机：iPhone 上的 Safari，或者安卓手机上的 Chrome，系统和浏览器保持新版本就行。iPad 和安卓平板也能用。
  • 网络：手机和电脑连同一个 Wi-Fi。不在同一个 Wi-Fi 时，两边都装上 Tailscale 也能连，见出门在外。
  • Shell：Mac 和 Linux 上，终端用的是你的登录 shell，zsh 和 bash 有完整的集成：Tether 知道命令什么时候开始和结束、退出码是多少、现在在哪个目录。Windows 上默认用 PowerShell，也有这些集成。其他 shell 也能用，功能少一些，见常见问题。

电脑睡着的时候，手机是连不上的。Tether 默认会阻止电脑因为闲置而睡眠，见菜单栏、通知区域和系统托盘。

安装

在下载页选你的系统。每个系统的完整步骤都在下载页上，这里是要点。

Mac

  1. Apple 芯片的 Mac 下载 Apple 芯片版，Intel 处理器的下载 Intel 版。打开 DMG，把 Tether 拖到「应用程序」文件夹。
  2. 推出磁盘映像，在「应用程序」里打开 Tether。

Tether 没有经过 Apple 公证，第一次打开会被 macOS 拦下来，放行一次就好：macOS 15 及更高版本，在「系统设置」→「隐私与安全性」里点「仍要打开」；macOS 12 到 14，在「应用程序」里按住 Control 键点按 Tether，选「打开」。完整步骤

接着 macOS 会问「允许“Tether”查找本地网络中的设备？」，点「允许」，不然手机连不上。问是否允许 Tether 发送通知时，也选「允许」，这样主窗口不在前面时也能收到提醒和回答按钮。

Windows

  1. 大多数电脑下载 x64 版，骁龙笔记本这类 ARM 电脑下载 ARM64 版，然后运行安装程序。
  2. 安装程序没有代码签名，Windows 会显示「Windows 已保护你的电脑」：点「更多信息」，再点「仍要运行」。
  3. 不需要管理员权限，装好后 Tether 会自己打开。

第一次打开时，Windows 防火墙会问是否允许 Tether 在网络上通信：勾上「专用网络」，点「允许访问」。电脑连的 Wi-Fi 也要是「专用网络」，不然手机连不上，见下载页上的说明。

Linux

  • Ubuntu、Debian：下载 .deb，在终端里运行 sudo apt install ./Tether-0.5.1-linux-amd64.deb，然后在应用菜单里打开 Tether，或者运行 tether。
  • 其他发行版：下载 AppImage，加上运行权限（chmod +x），再打开。

GNOME 要装托盘扩展才能看到 Tether 的图标（Ubuntu 已经带了），见常见问题。开着防火墙的话，要放行 7420 端口。完整步骤

打开之后会出现 Tether 的主窗口，菜单栏（Windows 上是通知区域，Linux 上是系统托盘）里也多了一个 Tether 图标。关掉窗口，Tether 还在后台运行。

连接手机

  1. 在电脑上打开配对窗口：点主窗口侧栏底部的「配对设备」，或者按 ⇧⌘P。也可以点菜单栏（Windows 上是通知区域，Linux 上是系统托盘）里的 Tether 图标，在弹出的面板里点「配对设备…」，或者在它的菜单里选「配对新设备…」。
  2. 用手机的相机扫描窗口里的二维码，打开识别出来的网址，配对会自动完成。别用微信扫一扫：微信会在它自己的浏览器里打开，配对码被用掉，却没法添加到主屏幕。不方便扫码时，在手机浏览器里打开窗口里写的地址（例如 192.168.1.8:7420），输入 6 位配对码。
  3. iPhone 上配对成功后，会提示你添加到主屏幕：在 Safari 的分享菜单里选「添加到主屏幕」。趁这个提示还开着完成添加，主屏幕上的 Tether 打开就是登录好的。安卓手机在 Chrome 的菜单里选「添加到主屏幕」。

二维码和配对码都只能用一次，5 分钟后失效。配对码连续输错 5 次就作废，这时改用扫码，或者在电脑上点「重新生成」。

配对窗口里的「复制链接」可以把配对链接发到手机上，在 Safari 里打开（安卓手机用 Chrome），效果和扫码一样。用微信发给自己的话，别在微信里直接点开，长按复制后粘到浏览器里。链接 5 分钟内谁先打开谁就能配对，别发到群里。

Mac 和 iPhone 之间可以用通用剪贴板直接粘贴；在主屏幕上的 Tether 里，粘到「粘贴配对链接」下面的输入框。

电脑同时有几个地址时（比如 Wi-Fi 和 Tailscale），配对窗口上方可以切换。扫哪个二维码，手机以后就用哪个地址连接。手机打不开地址的话，多半是防火墙或网络设置挡住了，见常见问题。

管理已配对的设备

点主窗口侧栏底部的「设备」，或者在 Tether 图标的菜单里选「已配对的设备…」。这里能看到每台设备是否在线、延迟多少、有没有开推送、哪天配对的。可以改名，也可以撤销：撤销后那台设备立刻断开，要重新配对才能再连。手机上也可以自己解除：「设置」→「在这台设备上解除配对」。

连多台电脑

每台电脑各配对一次。每台电脑的地址不同，主屏幕上会各有一个 Tether 图标。添加到主屏幕时可以把名字改成那台电脑的名字，免得几个图标都叫 Tether。

出门在外

手机和电脑不在同一个 Wi-Fi 时，可以通过 Tailscale 连接。Tailscale 会在你自己的设备之间建一个加密的网络，个人使用免费。配好以后，手机在哪儿都能连上电脑，锁屏时也能收到提醒。

Tether 里有一个向导带你一步步做完：在电脑上打开 Tether 的「设置」，点「出门在外也能用」。也可以点配对窗口里的「出门在外？」，或者 Tether 图标的面板和菜单里的「出门在外」。向导每隔几秒检查一次，做完的步骤自动打勾：

  1. 在电脑上安装 Tailscale。
  2. 登录 Tailscale。
  3. 手机也装上 Tailscale，登录同一个账号。
  4. 开启 HTTPS 地址：点「一键开启」。只有登录了同一个 Tailscale 账号的设备能打开这个地址，公网上的人访问不到。
  5. 设为手机访问地址。以后配对用的二维码和链接都用这个地址。
  6. 用手机扫新的配对二维码，添加到主屏幕，以后从这个新图标打开 Tether。
  7. 在手机上开启后台推送，见下面的锁屏推送。

Tailscale 的 iPhone 版不在中国大陆区的 App Store 里，要用其他国家或地区的 Apple 账户下载。已经有自己的 HTTPS 地址的，填到「设置」→「手机访问地址」，向导会跳过前 5 步。

在 Mac 上装 Tailscale

从 tailscale.com 下载，或者在 Mac App Store 安装。装好后点屏幕右上角菜单栏里的 Tailscale 图标，选「Log in…」登录。

在 Windows 上装 Tailscale

从 tailscale.com 下载安装程序，或者在 PowerShell 里运行：

winget install --id Tailscale.Tailscale -e

装好后点任务栏右下角通知区域里的 Tailscale 图标（可能收在「^」里面），选「Log in…」登录。

在 Linux 上装 Tailscale

在终端里运行 Tailscale 官方的安装脚本，它会要你输入密码：

curl -fsSL https://tailscale.com/install.sh | sh

再运行下面这行登录。它会打印一个网址，在浏览器里打开，登录你的 Tailscale 账号：

sudo tailscale up --operator=$USER

--operator=$USER 让你自己的账户也能管理 Tailscale，向导里的「一键开启」才不用 sudo。以前已经登录过 Tailscale 的，补运行一次 sudo tailscale set --operator=$USER 就行，向导遇到这种情况也会提示你。

局域网地址和 Tailscale 地址在手机上是两个不同的网址，要各自配对，主屏幕上也会是两个图标。经常出门的话，只用 Tailscale 的地址就够了，在家也能连。

锁屏推送

手机上开着 Tether 时，提醒会从屏幕顶部弹出来。想在锁屏或者用别的 App 时也收到，要打开后台推送。浏览器只允许 HTTPS 网址推送，iPhone 还要求从主屏幕打开（iOS 16.4 或更高版本），所以先按上面的向导配好 HTTPS 地址，从新的主屏幕图标打开 Tether。

然后在手机上点终端列表左上角的「⋯」→「设置」，在「后台推送」里点「开启」，允许通知。点「发送测试」，看看能不能收到。电脑上的向导最后一步也能给手机发一条测试提醒。

推送的内容是提醒的标题和一句摘要，加密后经 Apple 或 Google 的推送服务送到手机。安卓手机上的推送要经过 Google 的推送服务，在中国大陆或者没有 Google 服务的手机上通常收不到；打开 Tether 时的提醒不受影响。

日常使用

Tether 的菜单里说的「会话」，就是这里说的终端。正文里的快捷键按你现在用的电脑显示，完整的对照表见快捷键。

新建、改名、结束

  • ⌘T 在当前终端的目录里新开一个终端。侧栏顶部的 + 和手机上的 + 从主目录开始。
  • 终端的名字默认是当前目录的名字，cd 到别处会跟着变，主目录显示为「主目录」。Windows 上进到 \\服务器\共享 这样的网络路径时，名字不变，还是上一个目录的。按 ⇧⌘R，或者在侧栏里点右键，可以改名；名字留空就恢复用目录名。
  • ⌘W 结束当前终端，结束前会先问你；里面还有程序在跑的话，会写明是哪个程序。
  • 最多同时开 30 个终端。

终端概览

按 ⇧⌘\，或者点工具栏上的概览按钮，所有终端以实时缩略图平铺，每个缩略图上写着名字、目录和状态。点一下放大，再按一次缩回概览。等你回答的终端，回答按钮就在缩略图下面。也可以用方向键在缩略图之间移动，按回车放大。

查找

⌘F 在终端输出里查找，所有匹配都会标出来，并显示第几个、共几个。⌘G 和 ⇧⌘G 跳到下一个、上一个，在查找框里按回车、Shift+回车也一样（Windows 和 Linux 上还可以按 F3、Shift+F3），Esc 关闭。先选中一段文字再按 ⌘F，会直接查它。查找时有新的输出进来，也会停在当前的匹配上。手机上在「⋯」菜单里选「在终端中查找」。

历史联想

在提示符后打字时，光标后面会出现灰色的补全，按 → 接受。打了两个字以上，下面还会列出匹配的历史命令：↓ 选择，回车填入，Esc 收起。手机上，联想显示在键盘上方，点一下填进输入框。

联想用的是你平时的 shell 历史（zsh 的 ~/.zsh_history、bash 的 ~/.bash_history、PowerShell 的 PSReadLine 历史，或者 $HISTFILE 指定的文件），加上刚在 Tether 里执行过的命令。以空格开头执行的命令，Tether 不会记进联想；它会不会写进历史文件，由你的 shell 设置决定，例如 zsh 的 HIST_IGNORE_SPACE。

拖入文件和文件夹

从访达、文件资源管理器或文件管理器，把文件或文件夹拖到终端上，会出现两个选项：

  • 插入路径：把完整路径放到光标处，空格和特殊字符按当前的 shell 处理好，多个文件用空格隔开。
  • 进入这个文件夹：在终端里 cd 过去。拖的是文件，就进入它所在的文件夹。终端里有程序在跑时不能用。

拖到侧栏上，就在那个文件夹里新建一个终端。分屏时，拖到哪个窗格上就作用于哪个终端。拖入只在电脑上的 Tether 窗口里有，浏览器拿不到文件的路径。

终端尺寸

同一个终端，在电脑窗口和手机上的宽度不一样。Tether 的规则是谁在用就按谁的屏幕排版：你在手机上打开这个终端或者输入，它就换成手机的宽度；手机离开这个终端，或者你在电脑上切到它、打字，就变回电脑窗口的宽度。打开一个正在等你回答的终端时，尺寸不会变，免得提问被重新排版。

电脑窗口工具栏的右边显示终端现在的列数和行数。尺寸跟着别的设备时，会写着「尺寸跟随 iPhone」之类，点一下改回适配这个窗口。手机上也会出现「点此适配」。

如果不想让手机改动电脑上的排版，在手机的「设置」→「终端尺寸」里选「保持 Mac」（连的是 Windows、Linux 电脑时叫「保持电脑」），宽的内容左右滑动查看。

拷贝、粘贴、清屏和字号

  • 拷贝选中的文字：Mac 上按 ⌘C；Windows 和 Linux 上按 Ctrl+Shift+C，粘贴是 Ctrl+Shift+V，Ctrl+Insert、Shift+Insert 也行。单按 Ctrl+C 照常发给终端，用来中断程序。
  • ⇧⌘C 把终端里的文字放进一个窗口，可以随便选，也可以「复制全部」。手机上在「⋯」菜单里选「复制文本」，长按选择。
  • ⌘K 清屏。在终端里点右键，有拷贝（Windows 和 Linux 上叫「复制」）、粘贴、全选、清屏和「复制终端文本…」。
  • ⌘= 放大字号，⌘- 缩小，⌘0 恢复默认。
  • 按住 ⌘ 点终端里的网址，用浏览器打开。

关掉窗口和退出

关掉主窗口，终端照常运行，Tether 留在菜单栏（Windows 上是通知区域，Linux 上是系统托盘）里，手机照样能连。在 Windows 和 Linux 上第一次关掉窗口时，Tether 会发一条通知，告诉你图标在哪里。

要真正退出，按 ⌘Q，或者在 Tether 图标的面板或菜单里点「退出 Tether」。有终端开着时会先问你；关机、重启、注销时不会问，Tether 存好终端就退出。

下次打开时，终端按原来的名字回到原来的目录，之前的输出也在（每个终端最近约一千行）。Windows 上之前的输出在新的提示符上面，往上滚一下就能看到。退出时还在运行的程序不会恢复，要你重新运行。不需要这个功能的话，在「设置」→「重新打开时恢复终端」里关掉，已经存下的内容会一起删除。

菜单栏、通知区域和系统托盘

Tether 的图标在 Mac 的菜单栏里、Windows 任务栏右下角的通知区域里、Linux 的系统托盘里。

  • Mac：点图标弹出一个面板：开着几个终端、几台设备连着、延迟多少，还有手机可以用的地址，点地址就能拷贝。面板最上面的开关可以暂停手机访问，下面是「登录时自动启动」和「防止 Mac 休眠」。在图标上点右键是一个菜单，功能差不多，另外还能新建终端、打开已配对的设备。
  • Windows：单击图标弹出同样的面板，双击打开主窗口，右键是菜单。休眠开关在这里叫「防止电脑休眠」。Windows 11 会把新图标收进「^」里，可以把它拖到任务栏上。
  • Linux：没有弹出面板。单击图标通常会打开主窗口（有的桌面单击就是菜单），面板上的开关都在菜单里，菜单里还有「复制访问地址」和「设置…」。休眠开关叫「防止电脑自动休眠」。GNOME 要装 AppIndicator 扩展才有托盘图标，见常见问题；没有托盘时，关掉窗口后再打开一次 Tether 就能把窗口叫回来（AppImage 就再运行一次那个文件）。

有终端在等你时：Mac 的菜单栏图标旁边和程序坞图标上会显示有几个；Windows 的通知区域图标和任务栏按钮上会多一个标记；Linux 的托盘图标上会多一个标记。

  • 允许手机访问：关掉后所有手机立刻断开，终端继续运行。再打开，手机几秒内会自己连回来。
  • 防止休眠：默认打开。电脑不会因为闲置而睡眠，屏幕照常可以关。
  • 登录时自动启动：开机登录后，Tether 只在后台运行，不弹出窗口。

分屏

电脑上的 Tether 窗口可以切成多个窗格，最多 9 个，每个窗格放一个终端。手机上始终只显示一个终端。

  • 拖进来：把侧栏里的终端拖到某个窗格上：靠近哪条边就放在那一边，放在正中间就在那个窗格里打开它。已经显示在别的窗格里的终端会挪过来，同一个终端只出现一次。
  • 新开一个：⌘D 在聚焦的窗格右边新开一个终端，⇧⌘D 放在下面，都在当前目录。也可以在侧栏里右键一个终端，选「在右侧分屏打开」或「在下方分屏打开」。
  • 切换窗格：点哪个窗格，就在哪个里输入。⌘] 和 ⌘[ 按顺序切换，⌥⌘ 方向键 切到左右上下的窗格。
  • 调整大小：拖动窗格之间的分隔线；双击分隔线，两边恢复一样大。「均分窗格」让所有窗格一样大。
  • 关掉窗格：点窗格标题上的 ×，那个终端继续在后台运行。Mac 上也可以按 ⇧⌘W。「取消分屏」只留下聚焦的窗格，其余的终端继续在后台运行。

「均分窗格」「取消分屏」和「关闭这个窗格」在工具栏右边的「⋯」菜单里，Mac 上的「终端」菜单里也有。窗口变窄时只显示聚焦的窗格，变宽后恢复原样。分屏的布局会记住，下次打开还是这样。

在 Windows 和 Linux 上，Ctrl+Shift 加方向键只在分屏时用来切换窗格；不分屏时它照常发给终端，比如在 PowerShell 里按词选择文字。

提醒与一键回复

Tether 会在这些时候提醒你：

  • 命令跑完：运行超过设定时长（默认 10 秒）的命令结束时，附上退出码和用时。
  • 程序在等你输入：(y/n) 和 yes/no 确认、编号菜单、密码提示、「按回车继续」，还有 inquirer、clack 这类工具的提问，以及 terraform 的 Enter a value:。
  • AI 助手答完一轮，在等你回复，见AI 助手。
  • 终端响铃，或者程序自己发出通知（OSC 9、OSC 777）。
  • 输出里出现了你设定的关键词。同一个词一分钟最多提醒一次。

提醒出现在哪里

  • 电脑上的 Tether 窗口在前面、你在看别的终端时，窗口里弹出横幅。
  • 窗口不在前面时，发系统通知。在 Mac 和 Windows 上，需要你回答的通知会一直留着，直到你回答或者关掉；只是告诉你一声的，几秒后自己收起。
  • 手机上开着 Tether 时，屏幕顶部弹出横幅，往上划可以收起。
  • 手机锁屏、或者在用别的 App 时，要打开后台推送才能收到，见锁屏推送。

你正在看的那个终端不会再弹横幅。有终端在等你时，菜单栏、通知区域或系统托盘里的 Tether 图标上会有标记，Mac 的程序坞图标上会显示数字；手机上，终端左上角的返回按钮也会显示有几个。

一键回复

需要回答的提醒带着按钮：窗口里的横幅、系统通知（Linux 除外）、终端列表、概览缩略图，还有终端上方的提示条。不同的提问，按钮不一样：

  • (y/n) 提问：「y · 同意」和「n · 拒绝」。
  • 要求打完整单词的提问，比如 ssh 第一次连接时确认指纹：按钮发送完整的 yes 或 no。
  • 编号菜单：选项做成按钮，地方小的时候只放前几个；终端里的提示条和概览缩略图上还多一个 Esc。shell 里的编号菜单会自动补一个回车。
  • 密码提示：不提供一键回车，按钮带你到终端里自己输入。
  • 其他提问：「回车继续」。

系统通知上最多放三个选项；选项更多时，点通知打开终端处理。Mac 通知上的「稍后」只是把通知关掉。手机锁屏收到的推送没有按钮，点开会直接进到那个终端。Linux 上的系统通知没有按钮，点一下会打开那个终端，见常见问题。

一个问题在一处答完，其他地方的按钮和横幅会自动失效，挂着的通知也会收回。点到过期的按钮，Tether 不会发送，只提示「这个问题已经回答过了」，所以不会把一个 y 打进接下来运行的程序里。

调整提醒

在「设置」的「提醒」一栏里调整，所有设备共用一份：可以分别关掉「命令运行结束」「程序等待输入」「响铃和程序通知」，选多长的命令算长命令（5 秒到 5 分钟），也可以添加关键词，例如 ERROR。

AI 助手

Tether 认得这些 AI 编程助手：Claude Code、Codex、Gemini、Aider、OpenCode、Cursor（cursor-agent）、Amp、Goose、Qwen Code、Droid、Crush、Kimi、pi 和 Copilot。它按进程名和你输入的命令识别，用 npx、bunx、pnpm dlx 启动的也认得。

这些终端的状态会换成更贴切的说法：

  • 正在工作：助手在干活，它的界面上还显示着 esc to interrupt 之类的提示。
  • 等你回复：它答完了这一轮。
  • 需要确认：它在问你要不要允许某个操作。

助手答完一轮，Tether 会提醒你，提醒里是它回复的最后一行。点「回复」会打开这个终端，光标停在输入处。在 Mac 的系统通知里可以直接打字回它，文字和回车分开发送，助手不会把回车当成粘贴进来的换行。如果这时终端里已经不是助手了（比如退回了 shell），你写的这句话会拷贝到剪贴板，同时打开这个终端，不会被当成命令执行。

需要确认的菜单（例如 1. Yes、2. No），按钮直接按下对应的数字，不补回车。你在助手的输入框里打字、停顿，不算回答，也不会反复提醒；按回车发出去才算。

在手机上写长提示

快捷键栏上的「编辑」打开多行编辑框。写好点「发送」，整段作为粘贴发出，中间的换行不会被当成一行行命令执行；点「只粘贴」则只放进去，不按回车。在手机上先按 ⌥ 再按 ⏎，发出的是 Esc 加回车，在 Claude Code 里就是换行。

把截图交给助手

在手机上点输入栏左边的回形针，选照片或文件，它会传到电脑「下载」文件夹里的 Tether 文件夹，路径自动填进输入框。接着写一句「看看这张截图」，一起发出去就行。

手机上的操作

终端列表

  • 有新输出的终端前面有蓝点；在等你的终端会显示提问和回答按钮。
  • 底部的搜索框可以按名字、目录、命令和最新一行输出找终端。右上角的筛选按钮可以只看「运行中」或「等待输入」的。
  • 左上角的「⋯」里有「主机与连接」和「设置」。点顶部中间的标题也能打开「主机与连接」，里面能看到连的是哪台电脑、走的是局域网还是 Tailscale，以及延迟。

在终端里

  • 点顶部的标题，可以快速切换到别的终端。左上角返回按钮上的数字，是其他终端里有几个在等你或有新输出。
  • 从屏幕左边缘往右划，回到列表。
  • 单指上下滑动看历史输出，带惯性。在 less、man、git log 这类全屏程序里，滑动会换成方向键或滚轮，照样能翻。
  • 双指捏合调字号，右上角的 Aa 在几档字号之间切换。

输入栏和快捷键栏

  • 快捷键栏最左边的按钮切换两种输入方式。「整行」先在输入框里写好再发，适合中文和长命令；「实时」每按一个键就直接发给终端，适合 vim、菜单选择这类全屏程序。
  • 快捷键栏默认有：键盘、编辑、⌃、⌥、⇧、Esc、Tab、四个方向键、^C、粘贴、| ~ / - 和 ⏎。
  • ⌃ ⌥ ⇧ 是粘滞键，点一下，作用在下一个键上：⌃ 再打 c 就是 Ctrl-C，⌥ 加左右方向键按词移动，⇧ 加 Tab 反向补全。
  • 在「设置」→「快捷键栏」里自定义：拖动 ≡ 调整顺序，点 − 移除，点下面的按键添加。可以加的还有 ^D、^R、^Z、^L、Home、End、PgUp、PgDn 和常用符号。
  • 「粘贴」键只在通过 HTTPS 地址（比如 Tailscale 的 https 地址）打开时才能直接读剪贴板；用局域网地址时，长按输入框粘贴。
  • 浏览器支持语音识别时，输入栏左边会有麦克风按钮。手机键盘自带的听写也能用。

发送照片和文件

点输入栏左边的回形针，选照片或文件，它们会传到电脑「下载」文件夹里的 Tether 文件夹，文件名前面加上时间，路径自动填进输入框。单个文件最大 50 MB。

iPad 和平板

iPad、安卓平板和横过来的手机，用的都是这套触屏布局。iPad 接上键盘和触控板时，会换成和电脑窗口一样的布局，可以直接在终端里打字。

快捷键

Mac 上用 ⌘。Windows 和 Linux 上，Tether 的快捷键都是 Ctrl+Shift 加一个键，单按 Ctrl 的组合（Ctrl+C、Ctrl+R、Ctrl+D 这些）照常发给终端；只有调字号的 Ctrl+=、Ctrl+-、Ctrl+0 例外。

在电脑的浏览器里打开 Tether 时，有些快捷键被浏览器自己占着，用不了。Windows 和 Linux 上是新建和结束终端、上一个和下一个终端、全屏和退出（比如 Ctrl+Shift+T 是重新打开关掉的标签页）；Mac 上只有查找、终端概览、分屏和切换窗格的快捷键能用。用不了的，在浏览器里点侧栏和工具栏上的按钮。

设置

电脑上按 ⌘,，或者点侧栏底部的「设置」。手机上点终端列表左上角的「⋯」，选「设置」。

提醒（所有设备共用）

  • 命令运行结束：附带退出码和用时。
  • 多长算「长命令」：超过 5 秒、10 秒、30 秒、1 分钟或 5 分钟，默认 10 秒。
  • 程序等待输入：y/n 确认、密码提示、选择菜单等。
  • 响铃和程序通知：终端响铃，或者程序主动发出的通知。
  • 输出出现关键词：最多 20 个，同一个词一分钟最多提醒一次。

终端（只影响这台设备）

  • 终端配色：自动、浅色或深色。只改终端区域，其余界面跟随系统外观。
  • 字号：8 到 22。
  • 终端尺寸：手机上可以选「跟随手机」或「保持 Mac」（连的是 Windows、Linux 电脑时叫「保持电脑」）。
  • 输入方式：手机上可以选「整行」或「实时」。
  • 快捷键栏：手机上自定义按键和顺序。

这台电脑（只在电脑上）

在 Mac 上，这一组叫「这台 Mac」。

  • 重新打开时恢复终端：默认打开。
  • 允许手机访问：和 Tether 图标的面板、菜单里的开关是同一个。
  • 手机访问地址：留空时自动用局域网和 Tailscale 地址。填了以后，配对窗口里会多一个用这个地址的「自定义地址」。
  • 出门在外也能用：打开出门在外的向导。
  • 新终端使用：只在 Windows 上有。默认「自动」：装了 PowerShell 7 就用它，没有就用系统自带的 Windows PowerShell；也可以选「PowerShell 7」「Windows PowerShell」或「命令提示符」（cmd）。只影响之后新开的终端。
  • 版本和更新：Tether 的版本、「自动检查更新」开关，以及检查和安装更新的按钮，见更新。
  • 这里还能看到电脑的名字，并打开「管理设备」和「配对设备」。

手机上另有

  • 后台推送：「开启」和「发送测试」，见锁屏推送。
  • 安全：本机身份、连接的电脑和版本，以及「在这台设备上解除配对」。

「登录时自动启动」和「防止休眠」在 Tether 图标的面板和菜单里，见菜单栏、通知区域和系统托盘。

更新

从 0.5.1 开始，Tether 会自己检查更新。0.5.0 没有这个功能，要手动更新一次。

自动检查

Tether 开着的时候会去 GitHub 看有没有新版本：打开后半分钟看一次，之后每 6 小时一次；电脑睡眠醒来时，离上次检查超过 6 小时也会马上看一次。有新版本时：

  • 发一条系统通知「Tether 有新版本 x.y.z」，里面有这一版的简短说明。每个版本只提醒一次，点通知会打开设置里的更新那一行。
  • 设置按钮上出现一个小圆点，直到你更新。
  • Tether 图标的菜单里，「检查更新…」变成「更新到 x.y.z…」；Mac 和 Windows 上，点图标弹出的面板底部也会写着有新版本。

不想让它自己检查，在「设置」里关掉「自动检查更新」。关掉以后不再定时检查，但随时可以手动检查：Mac 上在「Tether」菜单里选「检查更新…」，Windows 和 Linux 上在 Tether 图标的菜单里选「检查更新…」，也可以在设置里点更新那一行。

更新时会发生什么

  1. 打开「设置」，在「有新版本 x.y.z」那一行点「更新」。点那条通知，或者在 Tether 图标的菜单里选「更新到 x.y.z…」，都会打开这一行。
  2. Tether 下载新版本，设置里显示下载进度。下载好以后核对签名和 SHA-256，对不上就不装，并告诉你哪里不对。
  3. 有终端开着时，Tether 会先问你：「更新 Tether 会关闭 N 个终端」。点「更新并重新打开」继续；点「取消」就先不更新，下次再点会直接用已经下好的文件。
  4. Tether 存好所有终端，退出，换上新版本，再自己打开，提示「已更新到 x.y.z」。

终端会按原来的名字回到原来的目录，之前的输出也在；正在运行的程序会停止，要你重新运行，所以最好等手头的命令跑完再更新。关掉了「重新打开时恢复终端」的话，更新后终端不会回来，确认框里也会写明。

更新时手机会断开，Tether 重新打开后几秒内自己连回来，配对不受影响。手机上的界面是电脑提供的网页，在手机上把 Tether 关掉再打开一次，就是新版本的界面。

各系统上的区别

  • Mac：Tether 要在「应用程序」文件夹里才能自己更新。从磁盘映像或「下载」文件夹里直接打开的，会提示你先把它拖进「应用程序」。更新以后不用再到「隐私与安全性」里放行，但 macOS 可能会再问一次是否允许 Tether 访问本地网络，点「允许」。
  • Windows：新版本在后台安装，不会弹出安装窗口，装好后 Tether 自己打开。
  • Linux AppImage：Tether 把新版本下载到 AppImage 所在的文件夹，直接替换原来的文件。这个文件夹要是你自己能写入的。
  • Linux .deb：.deb 装在系统目录里，Tether 没法自己替换。有新版本时一样会提醒你，按钮是「前往下载」：先退出 Tether，下载新的 .deb，再运行一次 sudo apt install ./文件名，然后打开 Tether。配置和终端都会保留。

检查更新失败时，见常见问题。

安全设计

  • 所有终端数据用 NaCl secretbox（XSalsa20-Poly1305）加密。每次连接都换一个新的会话密钥，每条消息带递增的计数器，重放或者乱序插入的消息都会被拒绝。
  • 扫码配对时，密钥只在二维码网址 # 后面的部分里。浏览器不会把 # 后面的内容发到网络上。
  • 用 6 位配对码配对时，手机和电脑先做一次临时的 X25519 密钥交换，再把配对码混进握手的密钥。同一个网络里旁听的人拿不到共享密钥，也就没法离线穷举这 6 位数。在线猜有次数限制：每个配对码最多错 5 次，同一个 IP 地址 5 分钟内失败 10 次，就要等一会儿才能再试。
  • 配对后，手机得到一把只属于它的设备密钥，存在手机的浏览器里。电脑上随时可以撤销。
  • WebSocket 拒绝跨站连接。电脑上的 Tether 窗口用一把单独的本机密钥。
  • 数据目录放在你自己的用户文件夹里；在 Mac 和 Linux 上，只有你自己的账户能读写。
  • 更新信息带着 Ed25519 签名，公钥内置在 Tether 里，签名对不上的更新信息会被忽略；下载的安装包要和签名信息里的 SHA-256 一致才会安装。

在公共 Wi-Fi 上：终端内容始终是加密的，但网页本身在局域网里是通过 HTTP 从电脑加载的。在酒店、咖啡馆这类你不信任的网络上，有人可能在中途改动网页。这种时候请通过 Tailscale 连接。

数据与隐私

Tether 没有账号，也没有自己的服务器，不收集使用数据。终端内容只在你的电脑和配对过的设备之间传输。会经过别处的只有两种情况：用 Tailscale 时，数据走你自己的 Tailscale 网络，全程加密；开了锁屏推送时，提醒的标题和摘要加密后经 Apple 或 Google 的推送服务送到手机。

Tether 自己联网只为检查和下载更新：它从 GitHub 下载一个公开的版本信息文件，你点了更新才下载安装包。这和用浏览器打开一个网页差不多，GitHub 能看到你的 IP 地址、系统类型、语言和 Tether 的版本号，但看不到你的终端、配对的设备这些内容。这些请求不带也不保存 Cookie，GitHub 没法靠 Cookie 把每次检查认成同一台电脑。不想让它联网检查，在「设置」里关掉「自动检查更新」。

数据存在哪里

数据目录
Mac 和 Linux 上是 ~/.tether，Windows 上是 %USERPROFILE%\.tether。config.json 里是端口、本机密钥、提醒设置、推送用的密钥和手机访问地址；devices.json 是配对过的设备和它们的密钥；restore/ 是为恢复终端存下的目录、名字和最近的输出；shell/ 是 Tether 给 zsh、bash 和 PowerShell 用的集成脚本。
手机发来的文件
「下载」文件夹里的 Tether 文件夹：Mac 上是 ~/Downloads/Tether；Windows 上是 %USERPROFILE%\Downloads\Tether，「下载」文件夹挪过位置的话跟着它走；Linux 上在你的下载文件夹里，例如 ~/Downloads/Tether 或 ~/下载/Tether。
窗口自己的偏好
比如分屏的布局。Mac 上在 ~/Library/Application Support/Tether，Windows 上在 %APPDATA%\Tether，Linux 上在 ~/.config/Tether。
更新时下载的安装包
Mac 上在 ~/Library/Caches/Tether，Windows 上在 %LOCALAPPDATA%\tether-updater，Linux 上在 ~/.cache/tether-updater（AppImage 直接下载到它所在的文件夹）。装好新版本后，旧的会自己清掉。
手机的浏览器
设备密钥和这台手机上的偏好，存在这个网址自己的存储里。在手机上解除配对会删掉密钥。

想把数据目录放到别处，先退出 Tether，再带上环境变量 TETHER_HOME 从终端启动它。

Mac：

TETHER_HOME=~/tether-data /Applications/Tether.app/Contents/MacOS/Tether

Windows（在 PowerShell 里）：

$env:TETHER_HOME = "$HOME\tether-data"; & "$env:LOCALAPPDATA\Programs\tether\Tether.exe"

Linux：.deb 装的用下面这行；AppImage 把 tether 换成那个文件的路径。

TETHER_HOME=~/tether-data tether

这个设置只对这一次启动有效：从「应用程序」、开始菜单、应用菜单或登录项打开时，用的还是默认的数据目录。在 Mac 和 Linux 上，关掉启动它的那个终端窗口，Tether 也会跟着退出。

历史联想读取你的 shell 历史文件，只在内存里用，不另存一份。用联想时，最近的历史命令（最多约 3000 条）会加密发给你正在输入的那台设备，只放在页面内存里，不会存到手机上。在 Tether 终端里执行的命令，照常写进你平时的历史。关掉「重新打开时恢复终端」，restore/ 里存下的内容会被删除。

常见问题

手机打不开电脑的地址

先看手机和电脑是不是连在同一个 Wi-Fi，Tether 的「允许手机访问」是不是开着。再按电脑的系统检查：

  • Mac：「系统设置」→「隐私与安全性」→「本地网络」里 Tether 有没有打开。开着防火墙的话，到「系统设置」→「网络」→「防火墙」→「选项…」里，看 Tether 是不是「允许传入连接」（macOS 12 在「系统偏好设置」→「安全性与隐私」→「防火墙」→「防火墙选项…」）。
  • Windows：电脑连的 Wi-Fi 要是「专用网络」，防火墙要允许 Tether 在专用网络上通信，见下载页上的说明。
  • Linux：开着 ufw 或 firewalld 的话，要放行 7420 端口，见下载页上的说明。

有的访客网络和公司网络会把设备互相隔开，这种情况用 Tailscale。手机上开着代理或 VPN 时（包括 Tailscale 的出口节点），局域网地址可能被它接管而打不开，先关掉再试，或者在它的设置里让局域网地址直连。

电脑的地址变了，主屏幕上的 Tether 连不上

主屏幕上的图标记的是配对时的地址。路由器给电脑换了 IP 之后，在新地址上重新配对一次就好。想少折腾，可以在路由器里给电脑固定一个 IP，或者用 Tailscale 地址配对，地址不会变。

从主屏幕打开 Tether，又让我配对

iPhone 上，主屏幕里的 Tether 和 Safari 不共用存储。配对成功后弹出的说明还开着时添加到主屏幕，登录信息会一起带过去。已经关掉了的话，在主屏幕打开的 Tether 里输入 6 位配对码，再配一次。

合上笔记本，手机还能连吗

不能。电脑睡着了，手机就连不上。「防止休眠」只阻止闲置睡眠，合上盖子还是会睡，除非接着外接显示器、在合盖模式下用。有的 Windows 笔记本用的是「新式待机」，屏幕关掉以后也可能进入睡眠，这时手机会断开。

退出 Tether 之后，终端里的程序呢

会停止。重新打开时，终端回到原来的目录，名字和最近的输出也在，程序要你重新启动。只是关掉窗口的话，什么都不会停。

提示端口 7420 被占用或者不能用

多半是已经有一个 Tether 在运行，比如在终端里用命令行启动的那个，先把它关掉，再打开 App。如果是别的程序占了 7420，可以把数据目录里 config.json 的 "port" 改成别的数字再打开 Tether，手机要用新地址重新配对。

Windows 上装了 Hyper-V、WSL 或 Docker 时，系统可能保留了包含 7420 的一段端口，Tether 用不了它。在 PowerShell 里运行下面这行，能看到被保留的端口范围，换一个不在里面的端口就行：

netsh int ipv4 show excludedportrange protocol=tcp

Linux 上看不到 Tether 的托盘图标

GNOME 默认没有系统托盘。Ubuntu 自带了托盘扩展，不用管。Fedora、Debian 这类原版 GNOME，要装「AppIndicator and KStatusNotifierItem Support」扩展，装好后在「扩展」里打开它，再注销、重新登录。KDE、Xfce、Cinnamon 这些桌面自带托盘。

Fedora：

sudo dnf install gnome-shell-extension-appindicator

Debian：

sudo apt install gnome-shell-extension-appindicator

没有托盘时 Tether 照样能用，只是关掉窗口以后看不到它：Tether 还在后台运行，手机照样能连，再打开一次 Tether，窗口就回来了（.deb 装的在应用菜单里打开，AppImage 就再运行一次那个文件）。要退出，在窗口里按 Ctrl+Shift+Q。开了「登录时自动启动」的话，登录后 Tether 不弹窗口，也是这样把窗口叫出来。

Linux 上的通知为什么没有按钮

Tether 在 Linux 上发的系统通知没有回答按钮，也没有回复框，所以 y/n、编号菜单这些提问没法在通知里直接回答，AI 助手的回复也不能在通知里打字。这类通知最后会写着「点击打开终端回答」：点一下会打开 Tether 和那个终端，回答按钮在终端上方的提示条里。

有的通知服务（例如 Xfce 的）会在通知上显示一个英文的「View」按钮，点它和点通知一样，会打开那个终端。

在 GNOME 的 Wayland 会话里，点通知或托盘菜单时，Tether 的窗口有时不会直接跳到最前面，而是出现一条「“Tether”已就绪」的提示，点它就行。

Windows 上用的是哪个 shell

装了 PowerShell 7（pwsh）就用它，没有就用系统自带的 Windows PowerShell。想换成命令提示符（cmd），在「设置」→「新终端使用」里选，之后新开的终端就用它。

PowerShell：你的 $PROFILE 照常加载，oh-my-posh、starship 这类提示符也能用。Tether 能知道命令什么时候开始和结束、退出码和当前目录，历史联想用的是 PSReadLine 的历史。没有 PSReadLine 时（比如开着读屏软件，或者卸掉了这个模块），目录和历史照常，但 Tether 看不出命令什么时候在跑，命令结束和等待输入的提醒就没有了。

命令提示符（cmd）：能用，功能少一些：命令结束的提醒里没有退出码；cmd 没有历史文件，联想里只有在 Tether 里执行过的命令。装了 Clink，或者用 AutoRun 改了提示符的话，Tether 就看不出命令的开始和结束，也跟不上当前目录。

这一版还不能直接选 Git Bash 或 WSL。可以在 PowerShell 的终端里运行 wsl 或 bash，只是 Tether 看不到里面的命令和目录。

我用 fish 或别的 shell

能用。Tether 的 shell 集成目前支持 zsh、bash 和 PowerShell。在其他 shell 里，Tether 靠前台进程判断有没有命令在跑，没有退出码，也没有历史联想。bash 在 Linux 上和平时打开终端一样读 ~/.bashrc，在 Mac 上按登录 shell 读 ~/.bash_profile 这些文件。

Windows 或 Linux 上按 Ctrl+Shift+F 没反应

微软拼音和 fcitx5 默认用 Ctrl+Shift+F 切换简体和繁体，输入法开着时会先拿走这个键。可以在输入法的设置里关掉这个快捷键，或者用工具栏「⋯」菜单里的「在终端中查找」。

支持 Intel 处理器的 Mac 吗

支持，从 0.5.1 开始。下载时选 Intel 处理器版。

标着「测试版」是什么意思

下载页上标着「测试版」的版本，功能和其他版本一样，也会自动更新，只是在真机上试得还不多，个别电脑上可能碰到问题。

Windows：还没有在很多台电脑上试过。PowerShell 里命令的识别、系统通知上的回答按钮这些，在个别电脑上可能不正常。

Linux：发行版和桌面环境很多，托盘、通知和窗口的表现各不一样，见上面关于托盘和通知的两条。

检查更新失败

Tether 要连上 GitHub 才能检查和下载更新。手动检查没成功时，设置里那一行写着「检查更新失败」，下面是原因：「网络连接失败，请稍后再试」是连不上 GitHub（在中国大陆，GitHub 有时连不上或者很慢）；「还没有找到更新信息，请稍后再试」一般是新版本正在发布；「更新服务器返回了错误」是 GitHub 那边出了问题。点「重试」会再检查一次。自动检查失败时不会打扰你。Tether 用的是系统的代理设置。

下载新版本没成功时，那一行直接写着原因，比如「下载的文件校验不通过，已删除，请重试」，点「重试」会重新下载。实在不行，可以过一阵再试，或者从下载页下载新版本，像第一次那样安装，数据和配对都会保留。

我的安卓手机没有 Chrome

Tether 支持的是安卓上的 Chrome，其他浏览器不保证能用。没有 Google 服务的手机收不到锁屏推送，打开 Tether 时的提醒照常。

同一个 Wi-Fi 里的人能看到我的终端吗

在自己家里或公司的网络里看不到。别人能打开电脑的地址，但没有配对就连不上，传输的内容也是加密的。在酒店、咖啡馆这类公共 Wi-Fi 上，见安全设计最后的提醒，最好通过 Tailscale 连接。不放心的时候，可以随时关掉「允许手机访问」。
